## لماذا رفيق المعتمر؟

يركّز المشروع على جعل رحلة المقارنة أكثر وضوحًا: عروض ذات مصدر ظاهر، رحلة تخطيط موجّهة، ودليل عملي للمسافر، مع طبقة مخصّصة لحلول الوكالات. لا يعالج المشروع الحجوزات أو المدفوعات الفعلية في نسخته الحالية.

### ما يتضمنه المشروع

| المحور | ما يقدّمه |
| --- | --- |
| **العروض المصدرية** | عرض السعر والمدة ومدينة الانطلاق كما ظهرت في المصدر، مع رابط مباشر وتاريخ تحقق. |
| **مخطط AI** | تجربة واجهة من خمس خطوات تساعد المستخدم على تضييق اختياراته. |
| **حلول الوكالات** | واجهات تجريبية لاكتساب العملاء المحتملين والاشتراكات والمواضع المدعومة بوضوح. |
| **تجربة عربية متجاوبة** | واجهة RTL بهوية «رحلات من نور» تعمل على سطح المكتب والهاتف. |
| **أداء محسّن** | تحميل متدرج للمسارات، صور WebP متجاوبة، وتأجيل الموارد غير الحرجة. |

## التقنيات

يُبنى المشروع باستخدام **React 19** و**TypeScript** و**Vite** و**Tailwind CSS 4**. يعتمد التوجيه على Wouter، والأيقونات على Lucide، وتُستخدم مكونات واجهة مبنية على Radix UI.

## التشغيل محليًا

يتطلب المشروع Node.js 22 أو أحدث وpnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

ثم افتح رابط Vite المحلي الظاهر في الطرفية. للتحقق والبناء:

```bash
pnpm check
pnpm build
pnpm start
```

## بنية المشروع

```text
client/
  src/
    components/     # مكونات واجهة مشتركة
    pages/          # مسارات وتجارب المنتج
    lib/            # بيانات العروض والمنفعة المشتركة
    contexts/       # حالة الواجهة العامة
server/             # خادم الإنتاج البسيط للملفات المبنية
shared/             # أنواع وثوابت مشتركة
```

## البيانات والمصادر

تظهر العروض في هذه النسخة كمحتوى مصدرّي قابل للرجوع إلى رابطه الأصلي. السعر والتوفر وشروط البرنامج قد تتغير؛ يجب التحقق من المصدر والوكالة قبل اتخاذ قرار أو دفع أي مبلغ. ظهور عرض في الواجهة لا يعني اعتمادًا رسميًا أو شراكة أو ضمانًا من المشروع.

## الأصول البصرية

تُحمّل صور البطل والشعار من مساحة تخزين مُدارة خارج المستودع لأجل النشر. إذا استُخدم المشروع خارج بيئته الحالية، استبدل روابط `/manus-storage/` بأصولك المستضافة أو بخدمة تخزين مناسبة قبل الإطلاق.

## الجودة والتطوير

يتضمن المستودع سير عمل GitHub Actions لتشغيل فحص TypeScript والبناء عند كل push وpull request. قبل فتح طلب دمج، شغّل `pnpm check` و`pnpm build` محليًا.
